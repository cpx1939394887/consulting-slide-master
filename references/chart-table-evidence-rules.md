# Chart And Table Evidence Rules

Charts and tables are evidence, not decoration.

## Chart Selection

| Need | Use |
|---|---|
| Trend over time | Line chart, slope chart, indexed trend |
| Before/after change | Slope chart, paired bars |
| Plan vs actual gap | Variance bridge, waterfall |
| Profit pressure | Profit bridge |
| Cost pressure | Cost bridge, stacked bar |
| Category comparison | Bar chart, ranked table |
| Mix or composition | Stacked bar, composition table |
| Decision options | Decision matrix, scoring table |
| Status tracking | Ledger table, RAG status table |
| Customer or action segmentation | 2x2 matrix |

## Required Chart Metadata

Every chart should include:

- title or local label
- unit
- time period
- source
- scope or definition
- visual emphasis for the key takeaway

## Table Rules

Good tables:

- are sorted or grouped intentionally
- highlight key rows or differences
- include units and definitions
- support the slide claim
- stay readable at presentation size

Bad tables:

- are pasted raw from source files
- have no conclusion
- are too large to read
- mix definitions without warning
- function as an appendix instead of proof
