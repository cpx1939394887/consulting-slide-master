# Consulting Color System

Use a restrained consulting palette for serious executive decks.

## Default Palette

| Token | Hex | Use |
|---|---|---|
| navy | `#05254D` | Titles, main structure, anchors |
| blue | `#005CB9` | Important neutral emphasis |
| cyan | `#00AAD2` | Logic lines, connectors, secondary emphasis |
| sky | `#E0EFF8` | Light blue fills |
| pale | `#F6F8FA` | Section fills and table bands |
| dark | `#262D37` | Body text |
| mid_gray | `#677482` | Notes, labels, secondary text |
| line_gray | `#CAD3DD` | Borders, grid lines |
| risk_red | `#B8242F` | Loss, risk, negative variance |
| fix_green | `#1C845F` | Improvement, positive action, recovery |
| amber | `#E58B23` | Constraints, pending decisions, transitional status |

## Rules

- White background by default.
- Use navy for slide titles and structural anchors.
- Use cyan for connectors and proof-flow emphasis.
- Use red only for risk, loss, negative variance, or stop signals.
- Use green only for improvement, recovery, approval, or action.
- Use amber for constraints, pending items, or caution.
- Avoid decorative gradients, icon clutter, and large dark backgrounds.
- Keep page chrome consistent, but vary body layout.
