# Density And Hierarchy Rules

This skill is optimized for high-density executive pages, especially Chinese business reporting.

## Density Principles

- Avoid large empty areas unless they create useful grouping.
- Do not reduce content to three vague cards.
- Keep important numbers large.
- Use tables when exact comparison matters.
- Use diagrams when relationships matter.
- Use charts when shape or magnitude matters.
- Use callouts only when they add interpretation.

## Minimum Readability

- Default minimum font: 12 pt.
- Table labels: 12 pt unless the user explicitly allows smaller.
- Footnotes can be 10-11 pt only if the target deck allows it; otherwise keep 12 pt.
- Do not let text overflow or collide.

## Page Density Targets

A typical executive page should contain:

- 4-7 meaningful information blocks
- one main proof object
- 2-4 highlighted numbers
- a clear source/scope note
- no more than one dominant chart/table family

## Chapter Pages

Chapter pages must not be empty title pages. Add:

- chapter claim
- what the chapter will prove
- key evidence objects
- output or decision expected from the chapter
