# Contact Sheet QA

The deck must pass rendered-preview QA before delivery.

## Required QA Steps

1. Export or save the final `.pptx`.
2. Render each slide to an image.
3. Generate a contact sheet.
4. Inspect the full deck at thumbnail size.
5. Fix weak pages before delivery.

## Checkpoints

| Check | Failure signal |
|---|---|
| Page rhythm | Many adjacent slides look identical |
| Density | Large empty areas with little content |
| Hierarchy | No clear main proof object |
| Title quality | Generic noun titles |
| Chart value | Chart does not prove the claim |
| Table quality | Raw table without interpretation |
| Font size | Text below accepted minimum |
| Overlap | Text, chart labels, or footers collide |
| Source discipline | Missing unit, date, scope, or source |
| Color semantics | Red/green/amber used inconsistently |
| Chapter pages | Empty section dividers |
| Language | Garbled text or encoding artifacts |

## Revise Before Handoff

If any issue appears in the contact sheet, revise the deck before final delivery. Do not rely on the user to find basic layout defects.
