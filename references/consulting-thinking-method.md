# Consulting Thinking Method

This skill does not summarize materials into slides. It converts materials into executive decisions.

## Core Chain

```text
Source materials
→ Evidence library
→ Management questions
→ Executive claims
→ Proof structures
→ Page-specific layouts
→ Boardroom-ready deck
```

## Start With The Decision

Before writing slides, identify:

- Who will read or hear the deck?
- What decision, alignment, funding, approval, or management action is needed?
- What are the top 3-5 questions leaders will ask?
- Which claims must be proven with evidence?
- Which claims are uncertain or require caveats?

## Convert Materials Into Claims

Avoid copying source text. Convert source materials into claim types:

| Source material | Convert into |
|---|---|
| Raw data | Evidence |
| Repeated description | Pattern |
| Conflicting numbers | Scope issue |
| Historical narrative | Timeline |
| Financial table | Driver analysis |
| Qualitative interview | Hypothesis or risk |
| Policy or market text | External condition |
| Action list | Management plan |

## Common Consulting Frames

- Situation, complication, question, answer
- Objective, gap, driver, action
- Baseline, variance, cause, implication
- Market, cost, sales, investment rhythm
- Options, trade-offs, risks, recommendation
- Now, next, later
- Stop, fix, scale

## Executive Claim Rules

A good claim:

- is a full judgment sentence
- can be understood from the slide title alone
- is supported by the main proof object on the page
- has a management implication
- avoids generic phrases such as "strengthen management", "improve efficiency", or "broad prospects"

Bad:

```text
Financial Performance
```

Good:

```text
Cash flow has recovered before earnings, but the business has not crossed the net-profit line
```
