# Content To Layout Decision Tree

Do not ask which template to use first. Ask what the page needs to prove.

## Decision Tree

| Page intent | Recommended layout family | Typical components |
|---|---|---|
| Establish status | Executive dashboard | KPI strip, status table, callout |
| Explain change over time | Trend view | Line chart, slope chart, timeline |
| Explain gap vs plan | Variance view | Bridge, waterfall, plan/actual table |
| Explain root causes | Diagnostic view | Issue tree, causal chain, quadrant |
| Explain structure | Decomposition view | Layer model, stacked bar, tree map, table |
| Compare options | Decision view | Option table, 2x2, scoring matrix |
| Define boundaries | Policy view | Matrix, redline table, allow/deny table |
| Show execution | Roadmap view | Timeline, Gantt, action table |
| Track compliance | Ledger view | Status table, RAG table, checklist |
| Summarize chapter | Synthesis view | Claim block, evidence list, output note |

## Anti-Repetition Rule

Do not repeat one fixed layout mechanically. If two adjacent slides use the same family, vary the composition:

- chart plus right-side interpretation
- table plus top KPI strip
- center claim plus surrounding proof points
- left/right opposing paths
- timeline plus bottom ledger
- full-width dense table with highlighted rows
- matrix plus action rules

If the slide would still look the same after replacing its text, redesign it.
