# Evidence To Claim Workflow

Build the evidence layer before slide writing.

## Evidence Library Fields

For every useful source fact, capture:

| Field | Description |
|---|---|
| data_name | Short name of the fact |
| value | Number, status, quote summary, or classification |
| period | Year, quarter, month, date, or project phase |
| unit | Currency, volume, percent, count, score, etc. |
| scope | Actual, forecast, budget, plan, audited, unaudited, tax-inclusive, ex-factory, delivered, etc. |
| source | Source file or link |
| page_or_sheet | Page, slide, sheet, table, or screenshot reference |
| confidence | High, medium, low |
| conflicts | Any conflicting source or definition issue |
| usable_pages | Slide types or claims this evidence can support |

## Classify Evidence

Use four evidence classes:

- `fact`: directly supported by source material
- `inference`: reasoned conclusion from facts
- `hypothesis`: plausible but not fully proven
- `unknown`: material gap or unresolved issue

Never present inference or hypothesis as fact.

## Source Discipline

Every number used in the deck must have:

- unit
- time period
- data scope
- source
- definition note when necessary

If sources conflict, write:

```text
Data definition differs across sources and requires confirmation.
```

Do not silently pick the prettier number.

## Claim Building

For each potential slide:

1. Select one management question.
2. Select one main claim.
3. Identify the strongest proof object.
4. Add supporting evidence only if it reinforces the main claim.
5. Add implication or action.
