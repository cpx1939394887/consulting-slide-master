# Component Taxonomy

Consulting Slide Master treats professional PPT templates as component sources, not fixed slide cages.

The component library is designed for 10,000+ indexed PPT objects extracted from professional template decks. Public examples in this repository are sanitized and illustrative; private or licensed template assets should not be committed unless distribution rights are clear.

## Component Roles

| Role | Purpose |
|---|---|
| `title_header` | Slide title, kicker, page number, section marker |
| `section_divider` | Chapter page or transition system |
| `kpi_strip` | Row of key metrics or status indicators |
| `metric_card` | Individual KPI or highlighted number |
| `comparison_table` | Compare options, entities, periods, or benchmarks |
| `ledger_table` | Track status, owner, action, source, or compliance |
| `timeline` | Show milestones or project history |
| `roadmap` | Show phased future actions |
| `decision_matrix` | Compare options or strategic choices |
| `issue_tree` | Break down causes or problem structure |
| `causal_chain` | Show why one event leads to another |
| `bridge_chart` | Explain variance, profit, cost, or revenue drivers |
| `chart_frame` | Chart container, axis system, legend, label grammar |
| `dashboard_strip` | Executive status overview |
| `callout` | Highlight interpretation, risk, or exception |
| `source_note` | Source, scope, definition, and caveat system |
| `process_flow` | Show operating process or decision sequence |
| `hierarchy_layer` | Show layered cost, org, product, or strategy structure |
| `map_region` | Region, market, or logistics view |

## Indexing Dimensions

Each component should be indexed by:

- visual role
- source template id
- source slide number
- bounding box
- text density
- color palette
- suitable use cases
- editable object type
- whether it is a top-level group or child shape
- whether it can be reused as a standalone component

## Recomposition Principle

The agent should not choose a full slide first. It should:

1. Identify the page proof need.
2. Search component roles.
3. Select compatible components.
4. Recompose a page-specific layout.
5. Apply the consulting visual system.
6. Check contact-sheet variety.
