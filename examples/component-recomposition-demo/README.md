# Component Recomposition Demo

This demo should show how a page is built from component roles rather than full-slide templates.

Suggested flow:

1. Page intent: explain revenue miss.
2. Select proof object: variance bridge.
3. Search components: title header, bridge chart frame, KPI card, source note.
4. Recompose layout.
5. Apply consulting color system.
6. Render and inspect contact sheet.
